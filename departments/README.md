# Department agent configuration

See [registry.json](registry.json) for the machine-readable department definitions and [the operating model](../docs/department-agents.md) for architecture, safety controls and rollout phases.

The registry is intentionally provider-neutral. Replace integration placeholders only when the relevant account is connected and its permissions have been reviewed. Do not add credentials to this directory.

**Current status:** blueprint/configuration only. AURA Guard does not yet run these department agents or invoke the listed external tools.
